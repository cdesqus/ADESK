PHASE 3 WHATSAPP SETTINGS UI IMPLEMENTATION
============================================

OVERVIEW
--------
Complete WhatsApp integration settings UI for AI-DESK frontend. Admins can manage WhatsApp sessions,
scan QR codes, manage engineer phone numbers, and view webhook status.

FILES CREATED
=============

1. TYPE DEFINITIONS
   File: src/types/whatsapp.ts
   Defines:
   - WhatsAppSession: Session info with status, phone number, and QR code
   - EngineerWAPhone: Engineer phone assignments with activation status
   - WAHookStatus: Webhook connection status and error logs

2. COMPONENTS
   
   a) SessionStatus (src/components/SessionStatus.tsx)
      - Displays session status with color-coded badges
      - Shows: Active (green), Awaiting scan (yellow), Inactive (red)
      - Includes phone number when available
   
   b) QRCodeDisplay (src/components/QRCodeDisplay.tsx)
      - Renders base64 QR code image
      - Loading state while generating QR
      - Error state with retry option
      - Copy to clipboard button
      - Refresh QR button
   
   c) WhatsAppSessionModal (src/components/WhatsAppSessionModal.tsx)
      - Modal form to create new sessions
      - Session name input with validation (alphanumeric only)
      - Two-step workflow: form -> QR display
      - Shows QR code after session creation
      - Status tracking: "Waiting for scan..." / "Connected"
      - Dismiss button after successful creation
   
   d) EngineerPhoneForm (src/components/EngineerPhoneForm.tsx)
      - Form to assign/edit phone numbers for engineers
      - Fields: Engineer dropdown, phone number (+62xxx format), group ID (optional)
      - Phone number validation
      - Submit/Cancel buttons
      - Supports both create and edit modes

3. PAGE
   File: src/pages/WhatsAppSettingsPage.tsx
   
   Features:
   - Active Sessions Table
     * Shows: Session Name | Phone | Status | Delete button
     * Refresh functionality syncs with Waha Plus
     * Color-coded status indicators
   
   - Add New Session
     * Button opens WhatsAppSessionModal
     * Shows QR code once created
     * Status updates in real-time
   
   - Engineer Phone Numbers Table
     * Shows: Engineer Name | Phone | Group ID | Active toggle | Actions
     * Add button opens EngineerPhoneForm in modal
     * Edit inline (opens form)
     * Delete with confirmation
     * Test button sends test message to phone
   
   - Webhook Status
     * Connected/Disconnected indicator
     * Last message received timestamp
     * Error log display (latest 5 errors)
     * Test webhook / Refresh button

INTEGRATION POINTS
==================

Backend APIs Expected:
- POST /whatsapp/sessions - Create session
- GET /whatsapp/sessions - List sessions
- GET /whatsapp/sessions/{id}/qr - Get QR code
- DELETE /whatsapp/sessions/{id} - Delete session
- POST /whatsapp/sessions/{id}/verify - Verify session
- POST /whatsapp/engineer-phones - Assign phone
- GET /whatsapp/engineer-phones - List assignments
- PATCH /whatsapp/engineer-phones/{id} - Update assignment
- DELETE /whatsapp/engineer-phones/{id} - Delete assignment
- POST /whatsapp/test-message - Send test message
- GET /whatsapp/webhook/status - Get webhook status
