DATABASE OBJECTS
================

New Table: monthly_reports
- id (VARCHAR(36) PRIMARY KEY)
- customer_id (INTEGER NOT NULL, FK to customers)
- month (INTEGER NOT NULL)
- year (INTEGER NOT NULL)
- csv_data (BYTEA)
- pdf_data (BYTEA)
- generated_at (TIMESTAMP DEFAULT CURRENT_TIMESTAMP)
- sent_at (TIMESTAMP NULL)
- sent_to_emails (JSONB DEFAULT '[]')
- created_at (TIMESTAMP DEFAULT CURRENT_TIMESTAMP)
- updated_at (TIMESTAMP DEFAULT CURRENT_TIMESTAMP)

Constraints:
- PRIMARY KEY: id
- FOREIGN KEY: customer_id → customers(id) CASCADE
- UNIQUE: (customer_id, month, year)

Indexes:
- idx_monthly_reports_customer_id
- idx_monthly_reports_month_year
- idx_monthly_reports_generated_at
- idx_monthly_reports_sent_at
- idx_monthly_reports_created_at
