API ENDPOINTS ADDED
===================

POST /api/reports/generate
  - Generate report on-demand
  - Input: customer_id, month, year
  - Returns: ReportData (JSON) with all metrics

GET /api/reports
  - List all reports with pagination
  - Query: limit, offset, customer_id
  - Returns: Array of report metadata

GET /api/reports/:id
  - Get single report details
  - Returns: Report metadata

GET /api/reports/:id/download
  - Download CSV or PDF file
  - Query: format (csv|pdf)
  - Returns: Binary file with proper headers

POST /api/reports/:id/resend
  - Resend report to email
  - Input: email address
  - Returns: Success/error

DELETE /api/reports/:id
  - Archive report (soft delete)
  - Returns: Success/error
