ROUTE ENDPOINTS:
================

PUBLIC (No Auth):
- POST /api/whatsapp/webhook - Receive messages from Waha Plus

PROTECTED (JWT Auth Required):
- POST /api/whatsapp/sessions - Create new WhatsApp session
- GET /api/whatsapp/sessions - List all sessions
- GET /api/whatsapp/sessions/:id/qr - Get QR code for session
- POST /api/whatsapp/sessions/:id/verify - Verify session connection
- DELETE /api/whatsapp/sessions/:id - Disconnect session
- POST /api/whatsapp/engineers/:id/phone - Link engineer WhatsApp phone
- GET /api/whatsapp/logs - View message activity logs

MESSAGE PATTERNS RECOGNIZED:
=============================

1. Create Ticket
   Pattern: "tolong buatin tiket <description>"
   Example: "tolong buatin tiket database tidak bisa diakses"
   Result: Auto-creates OPEN ticket, assigns engineer, notifies both parties

2. Progress Update
   Pattern: "TK-<id> progress: <message>"
   Example: "TK-123 progress: sedang menganalisis error logs"
   Result: Updates ticket to IN_PROGRESS, notifies customer

3. Close Ticket
   Pattern: "TK-<id> close: <resolution>"
   Example: "TK-123 close: database telah diperbaiki dan diverifikasi"
   Result: Updates ticket to RESOLVED, sends closure message to customer

4. Reopen Ticket
   Pattern: "TK-<id> reopen"
   Example: "TK-123 reopen"
   Result: Changes ticket to REOPENED, notifies engineer

5. Status Check
   Pattern: "status TK-<id>"
   Example: "status TK-123"
   Result: Sends current ticket status to customer
