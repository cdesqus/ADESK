ROLLBACK PLAN
=============

If deployment fails:

1. Stop backend: docker-compose down
2. Restore previous docker-compose.yml
3. Downgrade database: DROP TABLE whatsapp_*
4. Remove WhatsApp env vars
5. Restart: docker-compose up
6. Verify original functionality restored
